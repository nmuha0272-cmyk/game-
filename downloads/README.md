# Downloads

- **The PC game:** the models are now full detail, so the Windows game is about 1 GB, too big
  to keep here. Make it yourself in Godot (takes a minute):
  1. Open the project in Godot.
  2. Project -> Export... -> pick "Windows" -> Export Project.
  3. Save it as SubjectZero.exe. Double-click it to play.
  (Or just press F5 in Godot to play straight away.)
- **SubjectZero_Roblox.zip**: the Roblox game. Open `SubjectZero.rbxlx` in Roblox Studio and
  follow `HOW_TO_USE.txt`.
- **for_mixamo/**: the characters as zips that mixamo.com accepts, for making animations.
