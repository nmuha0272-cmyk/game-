DEEP STATIC GAMES - studio logo
================================
NOT in the game yet. (The empty .gdignore file makes Godot skip this folder.)

deep_static_logo_dark.png   the logo, dark and creepy look (1920x1080)
deep_static_logo_clean.png  the logo, clean and simple look (1920x1080)
deep_static_intro.mp4       the logo intro with sound (7.6 seconds)
intro_sound.wav             just the sound of the intro

What happens in the intro:
  0.0s  TV static switches on
  0.9s  the red signal line draws across
  2.1s  heartbeat spike: beep + deep "lub-dub", red flash
  2.2s  the TV-screen ring draws around it
  2.9s  DEEP STATIC flickers on letter by letter (electric crackles)
  3.9s  GAMES slides out
  5.0s  second heartbeat, glitch
  6.0s  the signal flatlines (long beep), static
  6.6s  old TV switches off to black
