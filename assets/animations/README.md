# Animation Placeholders

This folder contains placeholder animation resources. Replace these with actual animations.

## Structure

- `player/` - Player character animations (idle, walk, run, crouch, interact, etc.)
- `cutscenes/` - Cutscene-specific animations
- `monsters/` - Monster animations
- `props/` - Prop/object animations

## Usage

Add AnimationPlayer nodes to scenes and reference these placeholder animations.
Replace placeholders with actual AnimationLibrary (.tres) or Animation (.res) files.
