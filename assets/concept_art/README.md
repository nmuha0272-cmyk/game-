# Concept art

Reference sheets for the four characters, used when making the real 3D
models in Phase 10. Godot ignores this folder (because of `.gdignore`),
so these images are not part of the game build.

| File | Character | Main colors | First-person item |
|---|---|---|---|
| `son.webp` | The Son (Ethan), 19 | Brown canvas jacket, gray hoodie, jeans | Parent's dog tags |
| `journalist.webp` | The Journalist, 35 | Tan trench coat, dark turtleneck | Camera with flash |
| `guard_frank.webp` | The Guard (Frank) | Olive field jacket and cargo pants | Heavy flashlight |
| `son_ethan_3d_render.png` | Ethan, 3D model render (T-pose) | Brown jacket, gray hoodie, jeans, backpack | Dog tags |
| `engineer.webp` | The Engineer (elderly) | Navy overalls, tool belt, glasses | Adjustable wrench |
